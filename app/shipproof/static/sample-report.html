Critical Paid-AI route has no visible auth check 1 h

An endpoint that calls a paid model but never checks who is calling is free for anyone who finds the URL. This is the exact shape of a surprise four-figure bill.

Evidence

app/api/chat/route.ts

Fix

Check the session at the top of the handler (const { data: { user } } = await supabase.auth.getUser()), return 401 when missing, then attach the rate limit.

Critical Row Level Security not enabled on 1 table(s) 1–2 h

Supabase exposes your tables to the browser through the anon key. Without RLS, that public key can read, edit and delete every row — the most common data leak in AI-built apps.

Evidence

tables without RLS: orders

Fix

For every table run alter table public.<name> enable row level security; and add policies for select/insert/update/delete, for example create policy "own rows" on public.<name> for all using (auth.uid() = user_id); Dashboard-created tables are invisible here, so verify those too.

Critical Webhook handler does not verify the signature 45 min

An unverified webhook endpoint lets anyone POST a fake 'payment succeeded' event and get your product for free, or mark their own subscription paid.

Evidence

app/api/webhook/route.ts

Fix

Payments · confidence high

Critical Environment file is committed to the repository 20 min

A committed .env is readable by anyone with repo access and stays in git history even after you delete it. If the repo ever leaks, every key inside it leaks with it.

Evidence

.env

Fix

Remove the file from the repo (git rm --cached .env), add it to .gitignore, commit, and rotate every key it contained. Rewrite history if the repo is public.

Secrets & keys · confidence high

Critical Server-only secret referenced from browser code 30–60 min

Anything referenced from a component that runs in the browser can be read by a visitor. A service_role or provider secret here means full access for anyone who opens devtools.

Evidence

app/page.tsx:8 → SUPABASE_SERVICE_ROLE_KEY; app/api/admin/route.ts:3 → SUPABASE_SERVICE_ROLE_KEY; app/api/chat/route.ts:3 → OPENAI_API_KEY

Fix

Move the call into a server route/action. Keep these names out of client components entirely, and rotate the key if it was ever bundled.
