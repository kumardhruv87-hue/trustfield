Integrations

Ship the check with the code, not after it.

GitHub Action

Add a security check to every pull request. The action scans a deployed URL, comments the findings on the PR, and fails the job when critical issues are found.

Create .github/workflows/trustfield.yml:

name: Trustfield security scan
on:
  pull_request:
  workflow_dispatch:

jobs:
  trustfield:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: kumardhruv87-hue/trustfield@main
        with:
          url: https://staging.example.com
          fail-on: critical   # critical | high | never
          comment: true
          ai: false

Only scan apps you own or control. Use a staging URL if production needs a login. The action never scans anything that is not in the workflow file.

InputDefaultMeaning
url— (required)Public URL of the app to scan
fail-oncriticalFail the job on critical, high, or never
commenttruePost a summary comment on the pull request
aifalseRun the AI prompt-injection checks too

JSON API

Create a key in the admin dashboard (Integrations → Create API key). Send it as X-API-Key. Keys are stored hashed, limited to 500 scans/month each.

curl -s https://trustfield.dev/api/v1/scan \
  -H 'X-API-Key: tf_your_key' \
  -H 'Content-Type: application/json' \
  -d '{"kind":"url","target":"https://your-app.com","consent":true}'

Response (abridged):

{
  "ok": true,
  "id": "a1b2c3d4e5",
  "score": 72,
  "grade": "C",
  "locked": true,
  "total": 9,
  "counts": {"critical": 1, "high": 2, "medium": 3, "low": 3},
  "teaser": [{"title": "...", "severity": "critical"}],
  "report_url": "/r/a1b2c3d4e5"
}

Completion webhook

Create the API key with a webhook parameter (admin dashboard → Create API key) and Trustfield POSTs the finished scan to your HTTPS endpoint:

POST https://your-service.com/hooks/trustfield
X-Trustfield-Event: scan.completed
X-Trustfield-Signature: hmac_sha256(hex) over the raw body, key = your API key hash

{"event":"scan.completed","sent_at":"...","data":{"id":"...","score":72,"counts":{...},"teaser":[...]}}

Only HTTPS endpoints on public hosts are accepted. Delivery status is shown on the key in the admin dashboard.

Slack / Discord alerts

Get a message when a new paid report arrives or Watch finds something new. Paste a Slack incoming-webhook URL (or Discord webhook URL) into the Render env as SLACK_WEBHOOK_URL or DISCORD_WEBHOOK_URL; then use the “Test alert” button in the admin dashboard.
